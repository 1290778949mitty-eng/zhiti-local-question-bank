# 知题 · 本地题库

一个只保留核心流程的本地题库工具：按自定义分类保存试题，勾选试题后生成 Word 练习。

## 使用

在 macOS 上双击 `启动知题.command`。浏览器打开后即可使用，关闭启动窗口会停止服务。

首次打开时会自动放入 3 道示例题。可以新建、编辑、复制或删除试题，也可以建立任意层级的分类。

## 智能录题

点击“新建试题”后，可直接粘贴截图，或把图片拖进识别区域。系统会自动提取题干、题型、选项、答案、来源和知识点，并把几何图等配图单独裁出。保存前请检查识别结果；原始截图也会保留，方便核对。

智能识别可以连接 OpenAI 官方服务，也可以连接自建的 Sub2API 中转站。第一次通过“启动知题”打开时，会依次提示填写 API 地址、API Key 和视觉模型名称。Sub2API 地址填写到 `/v1`，例如 `https://你的域名/v1`。

配置仅写入本机的 `.env.local` 文件，不会显示在页面中。识别时题目图片会发送到你所配置的服务；选择稍后设置时，仍然可以使用手工录题。系统优先调用 `/v1/responses`，遇到不兼容时会自动尝试 `/v1/chat/completions`。

## 数据安全

题库数据保存在当前浏览器的本机存储中，不会上传到网络。不要随意清理这个站点的浏览器数据。

建议定期进入“分类与数据管理”，选择“导出备份”。生成的 JSON 文件可以在同一位置重新导入，也可用于迁移电脑。

## Word 组卷

在题库中勾选题目，点击底部“生成 Word”，可设置标题，并选择是否在文末附带答案与解析。文档为标准 `.docx` 格式。

## 当前范围

当前版本支持截图智能识别、原图留存、独立配图、纯文字、常用数学符号和选择题选项。暂未加入专业公式编辑器、批量导入和云端同步。
