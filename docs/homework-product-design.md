# 作业系统产品与交互原则

## 产品目标

作业系统帮助老师快速布置和掌握全班情况，帮助学生用最少步骤提交作业并看懂下一步。系统自动完成可以可靠完成的工作；无法辨认、漏页或无法匹配时明确退回重拍，不把拍摄问题算成学习问题。

## 界面原则

- 一个页面、一个状态、一个主要操作。
- 先结论、后证据；先当前任务、后历史信息。
- 能省的按钮就省，低频操作收进折叠区、弹层或更多菜单。
- 按钮横排、文案简短，不用竖排文字，不依赖图标猜含义。
- 教师端默认展示作业进度和异常；草稿设置与已发布概览不混在同一长页面。
- 学生端移动优先，保持“选择照片—提交—查看结果”的单一路径。
- 能力云只用于帮助理解，不展示伪精确分数；必须同时提供清晰的文字结论。

## 性能与无障碍

- 能力云按需加载，不引入重型 3D 依赖，不阻塞上传和首屏。
- 动画尊重 `prefers-reduced-motion`，所有能力节点提供键盘可访问的文字列表。
- 主要操作最小触控高度为 40px，桌面和 390px 移动端均不得产生页面级横向滚动。

## 中国课程知识图谱

知识图谱采用“课程节点—教材定位—题库题目—学生证据”的单一数据链路：

1. `cn-math-junior-v1` 提供稳定知识节点、父级领域、年级阶段和有向前置关系。
2. 人教版、北师大版和苏教版映射到同一知识节点；教材版本只是定位层，不复制三套知识图谱。
3. 题库题目和作业题目保存稳定 `taxonomyKeys`，AI 生成的自由知识标签仅用于辅助映射和人工校正。
4. 批改结果通过题目节点生成学生证据；自动退回的拍摄问题不进入知识图谱。
5. 教师端展示完整前置路径、题号证据、关系依据和教材定位；学生端只展示“先补—当前—下一步”。

数据与可视化运行时分离：`data/china-math-taxonomy.v1.json` 是版本化数据源，`schema/china-math-taxonomy.schema.json` 定义结构，校验器检查稳定 ID、引用完整性和 DAG 无环。Canvas 只负责按课程领域和年级阶段投影节点，不把业务分类写死在绘图代码中。

V1 当前是七至九年级数学课程骨架。三个教材版本已建立框架级映射，但具体册次与章节仍标注为“待校准”；未经过教材目录核对前，不得将其展示或宣传为精确章节定位。
